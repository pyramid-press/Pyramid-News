# Pyramid News — CEFR A1–C2 Interactive News Reader

A responsive, static English-learning site for computers, tablets, and phones. Choose A1–C2 to load the full news video first, then read the article and use sentence-by-sentence practice. Each level includes the supplied article text, vocabulary and phrase notes, illustration, male and female narration audio, and a three-question reading quiz.

The full videos include word-by-word karaoke highlighting. Select Normal 1.0× or Slow 0.8× in the page; the video and audio stay synchronized. An audio-only player is also available for either narrator. Sentence practice uses the English voices available in the device browser.

B1 and B2 use softer blue-gray reading surfaces. Each CEFR level retains its own visual theme. The site uses local files only and does not require a server or external library.

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload the contents of this folder to the repository root (including `videos/`, `audio/`, `illustrations/`, and `assets/`).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then select the `main` branch and `/ (root)`.
5. Open the Pages URL after publishing finishes.

`index.html` is self-contained for its layout, styles, article text, scripts, logo, and level illustrations. Video and audio files remain local assets in this package, so extract the complete ZIP before previewing or publishing. The editable source files (`style.css`, `app.js`, and `data.js`) are also included.
