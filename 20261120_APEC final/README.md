# Pyramid News — CEFR A1–C2 Interactive News Reader

Responsive static English-learning site for computers, tablets, and phones. Choose A1–C2 to watch the complete news video, read the article, and practice sentence by sentence. Every level includes its own article, vocabulary and phrase notes, illustrations, male/female narration, and three-part quiz.

The full videos include karaoke highlighting and offer Normal 1.0× or Slow 0.8× playback. Sentence playback uses the matching segment from that level's original video soundtrack and follows the media playback clock to avoid cutting off sentence endings. Sentence Practice includes the sentence audio, Chinese meaning, microphone recording and replay, plus optional speech-recognition text similarity scoring with a 75% pass threshold. Scoring availability depends on browser support for Speech Recognition; microphone recording requires permission on a secure GitHub Pages site.

The header uses the transparent Pyramid book logo and Pyramid News wordmark, with the motto “不積跬步 無以至千里”. C1 sentence cards use a light, high-contrast surface so the full sentence remains readable. B1 and B2 use softer blue-gray reading surfaces, and each CEFR level retains a distinct visual theme.

## Publish with GitHub Pages

1. Extract this ZIP.
2. Upload the extracted contents to the repository root, including `videos/`, `illustrations/`, `assets/`, and `index.html`. Do not upload the ZIP itself.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then select the main branch and `/ (root)`.
5. Open the Pages URL after publishing finishes.

`index.html` contains the site layout, styles, article text, scripts, quiz, and level illustrations. Video files and logo images are supplied as local assets. Keep the full folder structure when uploading. `style.css`, `app.js`, and `data.js` are included as editable source references.
