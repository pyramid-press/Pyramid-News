# Pyramid News — CEFR A1–C2 Interactive News Reader

A responsive, static English-learning site for computers, tablets, and phones. Choose A1–C2 to watch the full news video first, then read the article and use sentence-by-sentence practice. Each level includes the article, vocabulary and phrase notes, illustrations, male and female narration, and a three-part quiz.

The full videos include word-by-word karaoke highlighting. Select Normal 1.0× or Slow 0.8×; the video audio and highlighting stay synchronized. Sentence Practice plays the original male or female recording, at normal speed or 0.8×, for the selected sentence.

B1 and B2 use softer blue-gray reading surfaces. Each CEFR level retains its own visual theme. The site uses local files only and does not require a server or external library.

## Publish with GitHub Pages

1. Extract this ZIP.
2. Upload the extracted folder contents to the repository root, including videos/, audio/, illustrations/, assets/, and index.html. Do not upload the ZIP file itself.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then select the main branch and / (root).
5. Open the Pages URL after publishing finishes.

index.html is self-contained for its layout, styles, article text, scripts, logo, and level illustrations. Video and audio files remain local assets in this package, so extract the complete ZIP before previewing or publishing. The editable source files (style.css, app.js, and data.js) are also included.
